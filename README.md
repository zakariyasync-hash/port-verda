Port Verda is a 2D top-down open-world crime game in a fictional harbour city, built for make.fun's "Make GTA 6" bounty. Explore the city on foot and by car, steal cars, dodge the harbour police under a wanted system, and work six story missions plus two side jobs for fixer Mira — with traffic, pedestrians, combat, a HUD with minimap, saves and pause. Vanilla JavaScript ES modules, no libraries, no network: static files under `game/`.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
